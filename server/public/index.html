Your AI agents, side by side.

Project Coldfall is a free Mac app for running Claude Code, Codex, Gemini and other agents together. Each one gets a desk: its own terminal, its own folder and its own conversation, which it keeps. And the app tells you which desk is waiting on you.

Download for macOS View the code

macOS 13 or later. Free and open source (MIT).

What it does

It doesn't replace your agents. Each desk runs the vendor's own CLI in a real terminal, so your settings, hooks and memory work as they always have.

Desks that remember

Stop a desk or restart the app, and it picks up the same conversation. Rename it and it still does.

Knows what needs you

A line at the top names every desk waiting on you, oldest first. ⌘0 takes you straight there.

Any vendor

Claude Code next to Codex next to Gemini. Ask one agent to check another's work, or put one question to many folders at once.

What each desk has

See a desk's MCP servers, hooks, skills and plugins, and what's new since you last looked. Nothing gets added quietly.

Lighter desks

Switch off the MCP servers a desk doesn't need. A desk that never reads mail doesn't start a mail server.

Arranged your way

Group desks, drag them, hide the ones you're not using, or let the busiest groups rise to the top on their own.

Works with

Whatever you already have installed. If you have none yet, the app shows you how to install one.

Install

About a minute.

  1. Download the app, unzip it, and drag it to Applications.
  2. It isn't notarised by Apple yet, so macOS blocks the first launch. Paste this into Terminal:
    xattr -d com.apple.quarantine "/Applications/Project Coldfall.app"

    Or try to open it once, then go to System Settings, Privacy & Security, and click Open Anyway.

  3. Open it. It finds the agents you have and sets up a desk for each.

Rather build it yourself? The source builds with one script, no Xcode needed.

What it sends

Once a day the app checks for a new version. That check sends three things:
  • a random ID made on your Mac,
  • the app's version,
  • your macOS version.

That's how we count installs and tell you about updates. It never sends your desks, files, conversations or anything you type, the server keeps no list of IDs, and its code is public. You can turn it off in Settings.
